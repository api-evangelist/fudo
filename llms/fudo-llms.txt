# Fudo

> Fudo is a cloud-based point-of-sale and restaurant management platform used by more than 25,000 restaurants, bars, and cafes across Latin America. Its general-purpose public REST API (OpenAPI 3.1, JSON:API conventions) lets Pro-plan accounts read and write sales, payments, products, customers, expenses, inventory, and system configuration for reporting, BI, ERP, and custom integrations.

## API

- [Fudo API reference (RapiDoc)](https://dev.fu.do/api/): Interactive OpenAPI 3.1 reference for the v1alpha1 API.
- [Production base URL](https://api.fu.do/v1alpha1): All resource endpoints live under this path.
- [Authentication endpoint](https://auth.fu.do/api): POST apiKey + apiSecret to obtain a 24-hour bearer token.

## Conventions

- [API conventions](conventions/fudo-conventions.yml): JSON:API envelope, page[size]/page[number] pagination (default 250, max 500), PostgREST-style filter[column]=op.value filtering, bearer auth.
- [Authentication profile](authentication/fudo-authentication.yml): apiKey/apiSecret exchange for a bearer token, Pro-plan gated, role-scoped.
- [Error catalog](errors/fudo-problem-types.yml): JSON:API error objects (401/403/404/422).
- [Data model](data-model/fudo-data-model.yml): 18 entities and their JSON:API relationships.
- [Lifecycle](lifecycle/fudo-lifecycle.yml): uri-path versioning, current v1alpha1 (alpha).
- [Conformance](conformance/fudo-conformance.yml): OpenAPI 3.1, JSON:API, bearer auth.
